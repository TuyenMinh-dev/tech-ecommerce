\# Tech Ecommerce Platform (Microservices)



Dự án Hệ thống Thương mại Điện tử Phân tán Hiệu suất Cao cho ngành hàng thiết bị công nghệ \& linh kiện máy tính.



\- \*\*Tác giả:\*\* Lê Minh Tuyên (SICT-Đại học Công nghiệp Hà Nội)

\- \*\*Học phần:\*\* Phát triển phần mềm hướng dịch vụ

\- \*\*Kiến trúc:\*\* Microservices, Domain-Driven Design (DDD), Polyglot Persistence (PostgreSQL + MongoDB), Event-Driven Architecture (RabbitMQ).
